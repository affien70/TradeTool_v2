# TradeTool v2

Standalone Phase 2 foundation repository for TradeTool v2.

This repository contains only the modular scaffold, typed data contracts,
native Streamlit multipage shell, approved specification copy, and
baseline evidence pointers needed before business logic is ported.

Not implemented in Phase 2:

- ranking engines
- policy logic
- database access
- ML artifact loading
- holdings signal derivation
- market-data refresh
- training or backtesting
